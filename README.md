# Grand Prasadam Invite

Build a polished static invitation webpage for an Anna Prasadam event at Vinayaka Mandapam, designed for a typical Telugu local audience.

Content:
- Main event: అన్న ప్రసాదం
- Youth/Organized by: శ్రీ మణికంట్ట యూత్ అసోసియేషన్
- Venue: రంగపూర్ బోద్రై వద్ధా
- Time: సాయంత్రం 7.00 గంటల నుండి
- Include Vinayaka Mandapam context naturally in Telugu.

Design direction:
- Elegant, traditional Telugu aesthetic; premium/classy, restrained, not over-decorated.
- Maximum content in Telugu. Avoid unnecessary English.
- Use a refined ivory/cream, deep maroon, muted gold visual palette.
- Strong Telugu typography with excellent readability and proper rendering. Use a high-quality Telugu web font if available via Google Fonts.
- Opening animation MUST be a cinematic curtain-opening effect: two traditional fabric curtains start closed over the page and smoothly open on initial load to reveal the invitation. Keep it elegant and lightweight, with a skip/replay affordance only if it doesn't clutter the design.
- The revealed invitation should feel like a premium traditional printed invitation card brought to life on the web: centered composition, subtle ornamental borders, tasteful mandala/temple-inspired motifs, lots of whitespace, restrained gold accents.
- Mobile-first and responsive; it should look excellent on Android phones as well as desktop.
- No backend, no authentication, no database. Static frontend only.
- Add subtle entrance animations after the curtain opens, but do not make it flashy.
- Make the event details visually clear and easy to scan.
- Include a small footer line conveying a warm Telugu invitation such as “మీ అందరి రాకను సాదరంగా ఆహ్వానిస్తున్నాము” without adding unnecessary names/details.
- Ensure accessibility, semantic HTML, good contrast, and reduced-motion support.
- It must be suitable for deployment on GitHub Pages: client-side static assets only, relative paths, no server dependency.
- Do not invent an event date because none was provided.
- Build the complete working page, not a mockup.
